===============================================
POSSIBLE ISSUES & FIXES
===============================================

ISSUE 1: Objects spawn at (0, 0.26, 1.0)
-----------------------------------------
This means camera is at world origin (0,0,0)
→ Objects spawn 1 meter forward from origin
→ But YOU might be standing elsewhere!

FIX:
Camera should be moving with you in AR.
Check: AR Session Origin has AR Camera as child?

ISSUE 2: "In View: NO"
-----------------------
Objects are spawning but behind you or outside FOV

FIX:
Turn 360° slowly to find them
OR
Change spawnDistance to 2.0 meters

ISSUE 3: "Renderers: 0/94 visible"
-----------------------------------
Renderers disabled or materials transparent

FIX:
This is now auto-fixed in the code!
All renderers force-enabled on spawn.

ISSUE 4: Scale still 0.1 in logs
---------------------------------
You changed it in Inspector but didn't save

FIX:
1. Change objectScale to 0.5
2. File → Save Scene (Ctrl+S)
3. File → Save Project
4. Rebuild

===============================================
IF STILL NOT VISIBLE
===============================================

Check these in debug panel:

1. "Engine: NOT FOUND"
   → Prefab not assigned in Inspector!
   → Go to Unity, assign prefabs, rebuild

2. "In View: NO" but Pos looks reasonable
   → Turn phone/body 360° slowly
   → Objects might be to your side

3. "In View: YES" but still can't see
   → Check phone screen brightness
   → Objects might be too small still
   → Increase objectScale to 1.0

4. "Dist from Cam: 0.00m"
   → Objects at same position as camera
   → Increase spawnDistance to 2.0

5. Camera Pos: (0.0, 0.0, 0.0) always
   → AR tracking not working!
   → Check ARCore permissions
   → Reinstall app
