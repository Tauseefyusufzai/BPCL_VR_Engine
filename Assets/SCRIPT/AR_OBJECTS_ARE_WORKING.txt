ISSUE 1: Materials Look Washed Out/Transparent

The objects appear very light/faded in your screenshot.
This is because materials might be transparent or have wrong shader settings.

ISSUE 2: Not Anchored to Plane Properly

---------------------------
AR objects don't match real-world lighting,
making them look "pasted on" rather than integrated.

===============================================
QUICK FIXES TO APPLY
===============================================

FIX 1: Add FixARObjectRendering Script
---------------------------------------
1. In Unity Hierarchy → Create Empty GameObject
2. Name it "ObjectRenderer Fixer"
3. Add Component → FixARObjectRendering
4. Check these options in Inspector:
   ✓ Fix On Start
   ✓ Make Objects Opaque
   ✓ Fix Lighting
5. Save and rebuild

This will:
- Make all materials fully opaque (not transparent)
- Fix rendering mode
- Enable proper lighting
- Runs 3 seconds after start

FIX 2: Add FixARCamera Script
------------------------------
1. Select "AR Camera" in Hierarchy
2. Add Component → FixARCamera
3. This auto-runs on start
4. Save and rebuild

This ensures camera background renders correctly.

FIX 3: Check Your Prefab Materials
-----------------------------------
The main issue might be your Engine prefab materials!

1. In Project window, find your Engine prefab
2. Double-click to open Prefab editor
3. Select any mesh in the prefab
4. Look at Inspector → Materials
5. Check:
   - Shader should be: Universal Render Pipeline/Lit
   - Rendering Mode: Opaque
   - Base Map: Has a texture assigned
   - Color: NOT transparent (Alpha = 255)

If materials are missing or transparent:
- Assign proper textures
- Set Shader to URP/Lit
- Set Alpha to 1.0 (fully opaque)
- Set color to white or the desired color

IF STILL FADED AFTER FIX

Your Engine Prefab Materials Need Fixing:
-------------------------------------------

1. Select Engine prefab in Project window
2. In Inspector, expand Materials section
3. For EACH material:
   
   Click on material → In Material Inspector:
   - Surface Type: Opaque (NOT Transparent!)
   - Rendering Mode: Opaque
   - Blend Mode: Alpha (only if opaque)
   - Base Map: Assign texture
   - Base Color: White (255,255,255,255) ← Full alpha!
   - Metallic: 0.0
   - Smoothness: 0.5
   - Normal Map: Assign if available

4. Apply changes
5. Rebuild

===============================================
ALTERNATIVE: Manual Material Fix
===============================================

If scripts don't help, manually fix prefab:

1. Open Engine prefab
2. Select root object
3. In Inspector → Add Component → "Mesh Renderer"
4. Ensure "Materials" section has proper materials
5. For each material slot:
   - Create new material (Assets → Create → Material)
   - Set Shader: Universal Render Pipeline/Lit
   - Set Surface Type: Opaque
   - Assign Base Color texture
   - Set Base Color tint: Full white
   - Save

6. Rebuild
